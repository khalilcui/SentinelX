# SentinelX

SentinelX is a modern cybersecurity assessment platform designed to help security teams discover risks, analyze attack surfaces, and generate actionable security reports.

## Features

- Website security assessment
- SSL/TLS certificate analysis
- Security headers and cookie security checks
- Robots.txt and sitemap analysis
- Technology stack detection
- Network host assessment
- Open port and service detection
- Risk scoring and security recommendations
- PDF security report generation
- JWT-based authentication
- Responsive React dashboard
- Docker and PostgreSQL support

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Recharts
- Lucide React

### Backend

- FastAPI
- Python
- SQLAlchemy
- PostgreSQL / SQLite
- JWT Authentication
- ReportLab
- SlowAPI
